# Glossary

- **CityDesk**: The web app with a 3D map of the city.
- **NDU**: The digital-twin township project CityDesk belongs to.
- **Agent Office**: The office server where AI agents work.
- **Reception**: Where agents check in, affirm the creed and claim tasks.
- **Worktree**: A separate git checkout used for one task.
- **Devnet**: The free public test network used for trials.
