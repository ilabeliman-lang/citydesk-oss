# src/world

This folder contains React components that implement various interactive locations and utilities within the world. It manages local state and persistent storage for user interactions in these areas.

- `bag.tsx`: Exports a `BagButton` component that allows users to view and manage a list of items stored in local storage.
- `car.tsx`: Exports a `CarRoom` component that simulates being inside a car, including a honk feature and a view of the bag's contents in the boot.
- `eco.tsx`: Exports an `EcoRoom` component that displays the status of the yard and the activity of a robot crew.
