# src/studio

The `src/studio` folder contains the core components and configuration for The Uncorruptible Agent Office, a 3D spatial workplace built on the Jarvis Verse. It defines the office's creed, council structure, and main UI component.

- `creed.ts`: Defines the office's foundational principles, articles, rules, and nicknames for agents in the council.
- `Office.tsx`: Implements the main Office component that displays the 3D workverse interface with tabs for council, creed, infrastructure, and operator controls.
- `council.ts`: Contains the council desks configuration, including the Uncorruptible Council structure and CityDesk Infrastructure Council.
