# src/world/property-ui

This folder contains the user interface components and logic for the property records desk. it handles the display of property items and the acceptance of the property-record notice.

- `logic.ts`: Provides pure helper functions for calculating item capacity, formatting labels, and determining record tones.
- `ItemPicker.tsx`: A component for listing, adding, and removing property items associated with a specific scan.
- `ConsentSheet.tsx`: A component that displays the property-record notice and allows users to accept the consent version.
