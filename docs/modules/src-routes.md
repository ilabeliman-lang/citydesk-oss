# src/routes

This folder contains the route definitions and page components for the application using TanStack Router. It defines the primary views and navigation structure of the client.

- `admin.tsx`: Exports an administrative portal for managing business verification, operational status, bookings, fuel vouchers, and manager access.
- `block.tsx`: Implements a route that automatically redirects the user to the map page.
- `map.tsx`: Exports the main map page which handles the asynchronous loading and rendering of the WorldMap component.
