# src/world/office

This folder manages the office space within the 3D world, including the layout of the office floor and the roster of people working there.

- `roster.ts`: Defines the office roster data structure and related utilities for managing employee information.
- `OfficeFloor.tsx`: A React component that renders the 3D office floor layout using MapLibre GL.
- `office.server.ts`: Server-side logic for office-related operations, including data fetching and manipulation.
